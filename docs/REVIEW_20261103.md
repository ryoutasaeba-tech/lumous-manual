## 1. これは何をする仕組みか（1枚まとめ）

**ひとことで言うと**：LUMOUS（ルモウスジャパン）の「発送の仕事のやり方」を書いた説明書（マニュアル）を、ネットで見られるホームページにする仕組みです。README はありません。

**流れ**

```
[作る場所]                      [この仕組み]                         [見る場所]
別のパソコンの編集アプリ  →  generate.py  →  HTML 4枚 + index.html  →  update.sh が
(user-data.json に保存)     (HTML に作り直す)   + videos/ の動画 5本      GitHub に push
動画は IndexedDB にある  →  extract-videos.js                          → GitHub Pages で公開
                            (動画をファイルに取り出す)
```

| ファイル | やくわり |
|---|---|
| `generate.py` | `user-data.json`（※このリポジトリには無い）を読み、マニュアルごとの HTML と一覧 `index.html` を作る。動画のタグに動画ファイルをつなぐ。 |
| `extract-videos.js` | 編集アプリ（`localhost:3456`）のブラウザ内の保存場所から動画を取り出し、`videos/` に保存する。 |
| `update.sh` | 上の `generate.py` を動かし、変わっていたら commit して `main` に push する。 |
| `manual_0〜3_*.html` | できあがったマニュアル（作成日はすべて 2026/4/17）。 |
| `videos/*.mp4` | マニュアルに貼る動画 5本（合計約 83MB）。 |

**4枚のマニュアルの中身（発送の仕事）**

0. 発送が終わったら：差出票に名前と「次の日の日付」を書き、荷物と一緒に宅配ボックスへ入れ、鍵をかけて決めた場所に置く。
1. 梱包：割れ物・ブリキ看板はプチプチ、それ以外は OPP 袋。大きさで段ボール／封筒／宅配袋を選ぶ。
2. ラベル：Amazon 以外なら大きさで、そのまま印刷かクリックポスト。Amazon は追跡番号が要るのでクリックポストかゆうパックプリントR。
3. 商品確認：宛名ラベルを印刷 → 商品名を在庫システムで検索 → SKU を見て、棚・段ボール・ブリキ看板のどこにあるか探す。

**外へ何かを送るコードはあるか**：ありません。メール・LINE・X・Teams・メルカリ・BUYMA・Amazon・BASE を呼ぶコードは無く、外へ出るのは `update.sh` の `git push` だけです（Amazon・メルカリ・BASE は、マニュアルの絵や文字に名前が出てくるだけ）。つまり「同じ物を二重に送る」恐れは、仕組みとしてはありません。

## 3. 直したこと（小さくて安全なものだけ）

- `generate.py`：保存場所を環境変数（`LUMOUS_DATA` / `LUMOUS_OUT`）で変えられる（決めなければ今までと同じ）／0件・データ無しなら止まる／リンクを URL 用に変換／最終更新の空欄／重なるフローチャート／編集用ボタンの除去／動画が無いとき警告。`import` しても勝手に書き出さない形に整理。
- `update.sh`：新しいファイルも「変更」と数える／送り先の枝を `BRANCH=` で選べる（決めなければ `main`＝今まで通り）。
- `extract-videos.js`：保存先を環境変数 `LUMOUS_VIDEO_DIR` で変えられる／id を安全な名前にする／エラーでもブラウザを閉じる／0件なら失敗として終わる。
- `.gitignore`（`__pycache__/` だけ）と `tests/test_generate.py` を追加。

**あえて直さなかったもの**：マニュアルの中身、公開の仕組み（GitHub Pages）、動画の整理、秘密の数字や画像（#1〜#3）、`main` への push という決まり。持ち主の判断が要るためです。今ある 4枚の HTML は、元データが無いため作り直していません。
